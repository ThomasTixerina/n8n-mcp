# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2024-12-07

### Añadido
- Servidor MCP inicial para integración con Antigravity IDE
- Herramienta `create_n8n_workflow` para crear workflows básicos
- Herramienta `suggest_n8n_nodes` para sugerir nodos apropiados
- Herramienta `setup_github_integration` para integración con GitHub
- Herramienta `guide_automation_setup` para guía paso a paso
- Herramienta `connect_workspace` para configuración de workspace
- Herramienta `create_workflow_template` con 6 plantillas predefinidas
- Plantillas para: data_sync, notification_system, data_processing, api_integration, scheduled_task, event_driven
- Base de datos de sugerencias de nodos por categoría
- Guías de automatización paso a paso (5 pasos)
- Documentación completa en README.md
- Guía de inicio rápido en QUICKSTART.md
- Ejemplos detallados en EXAMPLES.md
- Guía de contribución en CONTRIBUTING.md
- Configuración de ejemplo para Antigravity IDE
- Soporte para TypeScript
- Licencia MIT

### Características
- Integración automática con Antigravity IDE
- Mensajes en español para mejor UX
- Soporte para múltiples tipos de triggers (webhook, schedule, manual, email)
- Sugerencias inteligentes basadas en keywords
- Configuración de webhooks automática
- Guía contextual según nivel de experiencia del usuario
- Plantillas listas para usar

### Documentación
- README completo con todas las herramientas
- Ejemplos de uso para casos comunes
- Guía de inicio rápido para nuevos usuarios
- Guía de contribución para desarrolladores
- Configuración de ejemplo incluida
